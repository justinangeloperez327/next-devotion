# Next Devotion

A modern devotion application built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

## Stack

- Next.js 16
- React 19
- TypeScript 7
- Tailwind CSS 4
- shadcn/ui

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## shadcn/ui

The shadcn registry is configured through `components.json`.

Add components with:

```bash
npx shadcn@latest add button
```

# Next Devotion

A modern devotion application built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

## Stack

- Next.js 16.4
- React 19.3
- TypeScript 7
- Tailwind CSS 4.3
- shadcn 4

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## shadcn/ui

The shadcn registry is configured through `components.json` using the current `base-nova` style.

Add components with:

```bash
npx shadcn@latest add button
```
